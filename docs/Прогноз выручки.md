# Как «Опекс» прогнозирует выручку

## Базовая модель

Основа — обычная линейная регрессия `LinearRegression` из scikit-learn, метод наименьших квадратов. На входе модели номер периода, целевая величина — выручка в единицах её валюты. Например, для значений 10, 20, 30, 40 она находит линию `выручка = 10 + 10 × номер периода`, где нумерация начинается с нуля. Для номера 4 прогноз равен 50. Поиск коэффициентов минимизирует сумму квадратов отклонений на обучающей истории.

Обрабатывается отдельный ряд каждой пары «инструмент + частота». Инструмент определяется источником, тикером и валютой. Квартальные и годовые значения образуют отдельные ряды. Модель получает только время и историю выручки. Финансовые коэффициенты, рыночные цены и параметры сценария используются в других разделах «Опекса».

## Варианты в версии 0.3.0

| Метод | Как работает | Когда сравнивается |
| --- | --- | --- |
| Линейный тренд | Одна прямая по всей непрерывной истории. | После достижения заданного минимума. |
| Тренд по недавней истории | Та же регрессия по последним четырём периодам или по настроенному минимуму, если он больше. | Когда можно сопоставить его с обычным трендом хотя бы на трёх прошлых точках. |
| Тренд с квартальной сезонностью | К номеру периода добавляются признаки места квартала в четырёхквартальном цикле. Модель учит общий наклон и типичные поправки для кварталов. | Только для Q, при наличии минимум двух полных циклов для обучения и хотя бы трёх прошлых точек для сравнения. |

Для каждого прогноза программа проверяет доступные варианты на одинаковых допустимых точках из последних восьми прошлых периодов и выбирает вариант с наименьшей средней процентной ошибкой. При одинаковой ошибке приоритет у более простого варианта. При короткой истории остаётся обычный тренд. После выбора программа обучает этот вариант на доступной истории и прогнозирует следующий период. Разрыв ряда обнуляет непрерывную обучающую историю для следующего прогноза.

Это выбор варианта одной регрессионной модели для временного ряда. Предсказание выдаёт выбранный вариант. Для сравнения **Naive** повторяет последнюю известную выручку и служит ориентиром вместе с прежним обычным трендом.

## Проверка без утечки

Для каждого исторического целевого периода мы строим прогноз из предшествующей истории. Выбор варианта происходит внутри этой истории на ещё более ранних прогнозах. Фактическая выручка целевого периода открывается только для оценки ошибки. MAPE — среднее абсолютное отклонение от положительной фактической выручки, выраженное в процентах. Модель, обычный тренд и Naive сравниваются на одинаковых допустимых точках.

| Квартальная история Microsoft | MAPE на 24 одинаковых точках |
| --- | ---: |
| Метод с выбором варианта | **4,10%** |
| Прежний линейный тренд | 4,49% |
| Naive | 4,73% |

Исходные 28 значений охватывают сентябрь 2019 — июнь 2026, по одной строке на квартал. В CSV указана ссылка на каждый релиз Microsoft. Для остальных эмитентов качество зависит от истории и характера выручки. На коротком контрольном списке Yahoo остаётся обычный тренд, поскольку доступной истории недостаточно для отбора сложных вариантов.
