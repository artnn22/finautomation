# Проверка MVP «Опекс»

Прогоны выполнены 18 ноября 2026 года на CPython 3.13.18. Пороги и параметры перечислены в YAML рядом с каждым набором. [Команды запуска и тестирования](../README.md), [техническое описание](Техническое%20описание.md).

В контрольном CSV сохранённые 41 цена покрывают отчётные даты и три отсечки доходности для списка AAPL, MSFT, SBER. Для новых дат запрашивайте дневную историю. Финансовые поля взяты из документов эмитентов. Для ранней истории AAPL и MSFT достаточно ряда выручки, а для SBER взяты доступные и однозначно сопоставимые статьи. [Apple 10‑K FY2022](https://www.sec.gov/Archives/edgar/data/320193/000032019322000108/aapl-20220924.htm), [Apple 10‑K FY2025](https://www.sec.gov/Archives/edgar/data/320193/000032019325000079/aapl-20250927.htm), [Microsoft FY2023](https://www.microsoft.com/investor/reports/ar23/), [Microsoft FY2025](https://www.microsoft.com/investor/reports/ar25/), [SBER FY2024](https://www.sberbank.com/common/img/uploaded/files/info/reporting_4q_1znmxst6_2024_en.pdf).

В контрольном сравнении Ridge с `alpha=1` для версии 0.2.0 получены MAPE 0,25% на учебном наборе и 6,71% на реальном списке из CSV. В версии 0.3.0 сравниваются варианты линейного тренда. Продолжительный контрольный ряд добавлен для Microsoft. В онлайн-прогоне для AMZN обнаружен пропуск квартала. Для годовой оценки Yahoo длины доступных рядов в этом прогоне оказалось недостаточно.

Даты AAPL из `examples/online/period_dates.csv` взяты из годовых и квартальных документов. [Годовой отчёт Apple за 2024](https://www.sec.gov/Archives/edgar/data/320193/000032019324000123/aapl-20240928.htm), [архив отчётности Apple](https://investor.apple.com/investor-relations/default.aspx), [отчёт за первый квартал 2026](https://www.apple.com/newsroom/2026/01/apple-reports-first-quarter-results/), [отчёт за второй квартал 2026](https://www.sec.gov/Archives/edgar/data/320193/000032019326000013/aapl-20260328.htm), [отчёт за третий квартал 2026](https://www.sec.gov/Archives/edgar/data/320193/000032019326000020/aapl-20260627.htm), [годовой отчёт Apple за 2026](https://www.sec.gov/Archives/edgar/data/320193/000032019326000026/aapl-20260926.htm).
